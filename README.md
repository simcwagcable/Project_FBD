# Проект: Верстка сайта "REVO Coffee"
## Проект
Этот репозиторий содержит базовый HTML-каркас и CSS-стили страницы, созданные по готовому макету кофейного магазина "REVO Coffee" с применением методологии БЭМ.
## Цель
Основная цель работы — освоение семантической разметки HTML5 и выполнение стилизации страницы согласно макету с использованием методологии БЭМ.
## Технологии
- HTML5
- БЭМ (Блок-Элемент-Модификатор)
